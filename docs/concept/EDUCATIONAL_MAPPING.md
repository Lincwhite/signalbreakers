## 1. COMPUTATIONAL THINKING FRAMEWORK

Signalbreakers teaches six core computational thinking concepts, aligned with CSTA (Computer Science Teachers Association) standards and international CS education frameworks:

| Concept | Definition | Real-World Analogy |
|---------|------------|-------------------|
| **Loops** | Repeating a sequence of instructions efficiently | Doing the same chore every day; following a recipe step multiple times |
| **Conditionals** | Making decisions based on conditions (if/then/else) | Taking an umbrella if it rains; choosing a route based on traffic |
| **Algorithms** | Step-by-step procedures for solving problems | Cooking instructions; GPS navigation directions |
| **Parallelism** | Doing multiple tasks simultaneously | Cooking multiple dishes at once; multi-lane highway traffic |
| **Abstraction** | Generalizing patterns to simplify complexity | Using a map instead of tracking every tree; summarizing a book |
| **Recursion** | Functions calling themselves; nested patterns | Russian nesting dolls; echoes in a canyon; fractals |

### Progression Logic

Concepts are introduced in this order because each builds on previous knowledge:

```
Loops → Conditionals → Algorithms → Parallelism → Abstraction → Recursion
  (D1)      (D2)        (D3)         (D4)         (D5)          (D6)
```

**Optimization** (District 7) and **Integration** (District 8) are meta-concepts that combine all previous concepts.

## 2. DISTRICT-BY-DISTRICT CONCEPT MAPPING

### District 1: Token Town — Loops (Repetition)

| Concept | Sub-Concept | Missions Teaching It | Real-World Connection |
|---------|-------------|---------------------|----------------------|
| **Loops** | Basic repetition (Repeat N times) | D1M01, D1M02 | Doing the same task multiple times efficiently |
| **Nested loops** | Loops within loops | D1M02, D1M04 | Rows of seats; grid patterns; repeating daily routines |
| **Loop variables** | Changing values each iteration | D1M04 | Loading different amounts; adjusting speed based on conditions |
| **Pattern recognition in loops** | Identifying repeating structures | D1M03, D1M05 | Recognizing music rhythms; spotting patterns in nature |

**Learning outcomes by end of District 1:**
- Player can write a loop to repeat an action N times
- Player understands that nested loops create grid-like patterns
- Player recognizes when a loop variable is needed vs. a fixed repetition count
- Player can identify repeating signal patterns and decode them using loops

### District 2: Cipher Ridge — Conditionals (If/Then)

| Concept | Sub-Concept | Missions Teaching It | Real-World Connection |
|---------|-------------|---------------------|----------------------|
| **Basic conditionals** | If/then/else branching | D2M01, D2M03 | Traffic lights; door locks; weather-based clothing choices |
| **Multiple conditionals** | If/elif/else chains | D2M02 | Grading systems (A/B/C/F); signal routing based on type |
| **Conditionals in loops** | Decisions inside repeated sequences | D2M03, D2M05 | Checking each item in a list; filtering data streams |
| **Nested conditionals** | If statements within if statements | D2M04 | Complex decision trees; game AI behavior trees |

**Learning outcomes by end of District 2:**
- Player can write an if/then/else statement to make decisions
- Player understands that multiple conditions require elif chains
- Player recognizes when conditionals should be inside vs. outside loops
- Player can build a conditional decision tree for complex routing problems

## 3. MISSION-BY-MISSION LEARNING OBJECTIVES

### District 1: Token Town — Loops

| Mission | Primary Concept | Secondary Concept | Learning Objective | Assessment Criterion |
|---------|-----------------|-------------------|-------------------|---------------------|
| D1M01 | Basic loops | None | "Player can write a loop to repeat an action N times" | Player successfully uses Repeat() instead of writing each step individually |
| D1M02 | Nested loops | Pattern recognition | "Player understands that loops can contain other loops" | Player creates grid pattern using nested Repeat() calls |
| D1M03 | Loops + signal decoding | Pattern recognition | "Player applies loop concept to decode repeating signals" | Player identifies repeating signal pattern and programs decoder with correct repetition count |
| D1M04 | Loop variables | Adaptation | "Player understands that loops can include changing values" | Player uses variable in loop to handle different package counts per house |
| D1M05 | Complex loop patterns | Integration | "Player combines multiple loop concepts into one solution" | Player programs festival display with base pattern + periodic variation |

### District 2: Cipher Ridge — Conditionals

| Mission | Primary Concept | Secondary Concept | Learning Objective | Assessment Criterion |
|---------|-----------------|-------------------|-------------------|---------------------|
| D2M01 | Basic conditionals | Decision making | "Player can write an if/then/else statement" | Player routes robot correctly based on signal color |
| D2M02 | Multiple conditionals | Multi-way branching | "Player understands elif chains for handling many cases" | Player routes signals to correct destinations using if/elif/else |
| D2M03 | Conditionals in loops | Combined logic | "Player can place conditionals inside loop structures" | Player delivers packages correctly, skipping closed houses and doubling urgent ones |
| D2M04 | Nested conditionals | Decision trees | "Player understands if statements within if statements" | Player opens gates by checking time AND signal availability |
| D2M05 | Full pipeline (loops + conditionals) | Integration | "Player builds complete program using all learned concepts" | Player processes mixed signals with routing, filtering, and extraction in one program |

## 5. ASSESSMENT RUBRIC

### Mission Completion Rubric (For Teachers)

| Level | Description | Indicator |
|-------|-------------|-----------|
| **Emerging** | Player completes mission with hints or trial-and-error | Uses Explorer mode; requires ≥2 hints per mission |
| **Developing** | Player completes mission independently but inefficiently | Uses Engineer mode; score 50–79% (uses more instructions than optimal) |
| **Proficient** | Player completes mission efficiently and correctly | Uses Engineer mode; score 80–99%; understands concept |
| **Advanced** | Player solves mission optimally, possibly in Blackout mode | Uses Blackout mode; perfect scores; explores alternative solutions |

### Concept Mastery Checklist (For Teachers)

After completing Districts 1–2, students should be able to:

- [ ] Explain what a loop is and give a real-world example
- [ ] Write a simple loop that repeats an action N times
- [ ] Explain nested loops and create a grid pattern using them
- [ ] Explain what a conditional (if/then/else) is and give a real-world example
- [ ] Write a conditional statement that makes a decision based on input
- [ ] Combine loops and conditionals in a single program
- [ ] Identify which computational thinking concept is being used in a given puzzle

## 6. TEACHER RESOURCES

### Suggested Classroom Activities

| Activity | District | Time Required | Materials |
|----------|----------|---------------|-----------|
| **Unplugged loops** | D1 | 20 minutes | Paper, pencils, "robot" path grids |
| **Human conditionals game** | D2 | 25 minutes | Sign cards (LEFT/RIGHT), student volunteers as robots |
| **Signal decoding race** | D3–4 | 30 minutes | Printed signal patterns, Codebook reference sheets |
| **Algorithm design challenge** | D5–6 | 40 minutes | Whiteboards, markers, sample problems |

### Discussion Prompts (Post-Mission)

| Mission | Prompt | Concept Reinforced |
|---------|--------|-------------------|
| D1M03 | "Why is using a loop better than writing each step individually?" | Efficiency, abstraction |
| D2M01 | "Can you think of a real-life situation where you need to make a choice based on a condition?" | Conditionals in daily life |
| D2M05 | "What happened when you had to process multiple types of signals at once? How did you organize your program?" | Parallelism, organization |

### Extension Activities (For Advanced Students)

- **Challenge mode:** Complete each mission using the fewest instructions possible (Engineer/Blackout modes)
- **Code review:** Share solutions with classmates and compare approaches
- **Create your own puzzle:** Design a mission for a friend using concepts learned in Districts 1–2
- **Real-world mapping:** Identify computational thinking concepts in everyday technology (traffic lights, vending machines, etc.)
