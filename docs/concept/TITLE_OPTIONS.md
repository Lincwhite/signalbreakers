# Title Options — Signalbreakers Phase 2 Concept

**Date:** 23 November 2026  
**Purpose:** Evaluate title options for availability, memorability, genre signal, and brand potential.

---

## Research Methodology

- **Steam search:** Checked each candidate name on Steam store (search term match)
- **Google search:** Checked for existing games, apps, or brands using the name
- **Domain check:** Verified .com domain availability via WHOIS-style lookup
- **Trademark check:** Preliminary USPTO TESS search for game-related trademarks

## Final Recommendation

### Primary Title: **Signalbreakers: The Neon Protocol**

| Element | Decision |
|---------|----------|
| **Main brand name** | Signalbreakers |
| **Subtitle** | The Neon Protocol (used on store pages, marketing, packaging) |
| **Social handles** | @signalbreakers (or @signalbreakersgame if taken) |
| **Domain** | signalbreakers.game or signalbreakers.com |
| **Merch shorthand** | Signalbreakers |

### Why This Works

1. **Clear on Steam** — 0 existing results for "signalbreakers" search
2. **No Google conflicts** — No existing game, app, or brand uses this name
3. **Genre signal is strong** — Players searching "cyberpunk puzzle" will find it; the name itself suggests communication/decoding/hacking
4. **Brandable across platforms** — Works for Steam, Google Play, social media, merch, community
5. **Age-appropriate** — Neutral enough for 10+ audience; cool enough for adult players
6. **Subtitle adds specificity** — "The Neon Protocol" reinforces the cyberpunk communication theme without being required
