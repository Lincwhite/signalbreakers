# SIGNALBREAKERS: THE NEON PROTOCOL

A cyberpunk STEM puzzle-adventure game for Windows and Android.

## Overview

Signalbreakers is a narrative-driven puzzle game set in LUMA-9, a neon-lit floating city whose communication network is failing due to "The Static" — a mysterious interference pattern corrupting all messages. Players take on the role of a young signal engineer who must decode damaged transmissions, repair broken protocols, build secure communication systems, and uncover the truth behind the interference.

The game teaches real computational thinking concepts through gameplay:
- **Tokenization** — splitting data into meaningful units
- **Codebooks** — numeric mappings for tokens
- **Relation graphs** — typed connections between data elements
- **Finite-state machines** — parser construction and validation
- **Error detection** — debugging corrupted messages
- **Frequency analysis** — identifying patterns in encrypted data
- **Authentication** — checksums, nonces, MACs, and secure protocols

## Key Features

- 8 unique districts, each teaching different cybersecurity concepts
- Three difficulty modes: Explorer, Engineer, Blackout
- ADHD-friendly design with short missions, optional timers, undo/retry
- Works offline on Windows and Android
- No forced ads, no loot boxes, no energy systems
- Professional premium PC presentation + accessible mobile experience
